<b>SrcPanel</b> is an web-based administration panel intended for communities, allowing admins to manage bans, notes, and players & admins, manage server files (maps, addons, plugins), create intra-admin discussions, view audit logs (in-game and panel activity), manage servers (perform actions, console, live status, create instances), and lastly custom documentation (tutorials/pages/plugin docs for admins)

SrcPanel was designed primarily for <b>source engine</b> servers, specifically Left 4 Dead 2, but can work with other servers with either games on [Gamedig's supported list](https://github.com/gamedig/node-gamedig/blob/master/GAMES_LIST.md) or with a custom plugin using the panels' custom live server protocol.

Check out the [demo site at demo.srcpanel.app](https://demo.srcpanel.app) to see example supported servers.

SrcPanel has been in development for at least 5 years on and off and was designed for my own L4D2 community to allow them to manage aspects without my help. It has slowly evolved over time as needs changed and new ideas formed to what it is today.
