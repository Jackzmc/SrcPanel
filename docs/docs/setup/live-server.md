A part of the admin panel is a live server that can send state from within a game, live, to a the panel. It is an alternative to querying the status on an interval which can be unreliable or difficult in some scenarios.
The live server works as a TCP server on the admin panel that clients (gameservers) connect to and send data towards.

It also can be an alternative to RCON, by allowing commands to be sent from the panel to the client.

Currently the only implementation is for source engine games, and only for Left 4 Dead 2. 

The server normally runs on TCP 7888 and is unencrypted. Authentication is done using JWT tokens generated from panel. 

## Generating Tokens

The token can be generated by a logged in user at `/api/servers/:id/generate-jwt`, replacing `:id` with the server's id. It is returned as a plaintext string.

## Supported Games

### Left 4 Dead 2

Includes survivors and infected, survivors' health, movement throughout level, and items. It shows the state of the finale and the map. 
Supports sending commands as well.
