# Creating a Spray

Creating a spray isn't very difficult. The recommended tool for this is [Paint.NET from getpaint.net](https://www.getpaint.net/). The recommended size of spray is something square, I use 512 x 512 pixels.

If you don't want to use paint.net, and you have an square image already, you can use a free converter tool like [PNG to TGA](https://convertio.co/png-tga/) or [JPG to TGA](https://convertio.co/jpg-tga/).

Sprays in L4D2 are .TGA image files, just like .PNG or .JPG. There are two types of TGA, one with transparency (32 bit) and one without (24 bit). You'll want the 32 bit option when saving in paint.net so it keeps the transparency of the spray.

# Adding a Spray

You can add a spray from any directory on your computer, but I recommend making a `sprays` folder in your L4D2 folder so you can easily switch between different sprays.

To create that folder:
1. Open up your steam library and open the properties by clicking the gear icon.
![steam_properties.png](/img/tutorials/steam_properties.png)

2. Click on **Installed Files** and then click [**Browse**]. This will open your Left 4 Dead 2 install folder.
![steam_browse.png](/img/tutorials/steam_browse.png)

3. Open the `leftdead2` folder, and then create a new folder called `sprays`.

4. Add your TGA files to the folder

## In-Game

To now select the spray in game, go to **Options** -> **Multiplayer** -> **Import Spray**.
This will open in the `left4dead2` folder, so just find the `sprays` folder and open that, and then select the file.
![l4d2_sprays_folder.png](/img/tutorials/l4d2_sprays_folder.png)
